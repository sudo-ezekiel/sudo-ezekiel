## Jigsaw Addict

A collaborative 3D jigsaw puzzle: drop in, drag pieces, connect them with friends and race to
finish the picture. Unity 6 client, Cloudflare Workers and Durable Objects backend, a Node bot
fleet, CI with a 100% coverage gate and a Docker-based local stack.
